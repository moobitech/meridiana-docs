# Roadmap

What is planned for Meridiana, in no fixed order and without dates: plans can change. To ask for a
feature or vote for one, open an issue in this repository.

## Planned

### Resource timeline

A scheduler with one row (or column) per resource — rooms, people, equipment, vehicles — on a
horizontal time axis:

- day, week and month timelines, with resources grouped and collapsible;
- drag an event along the time axis and from one resource to another, resize it, create one by
  selecting a range;
- events of the same resource that overlap stacked within its row;
- the same API and themes as the other views, in Angular, React and React Native.

It will be a paid add-on, never part of the Community plan: see [Pricing](pricing.md).

### Hosted demo

A public page with the demos of the three frameworks, to try every view and interaction without
installing anything. Until then, ask for a live demo at the contact in [Pricing](pricing.md).
